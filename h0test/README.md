# Статистическое тестирование выходных последовательностей ГСЧ

Во время разработки генератора случайных чисел возникает необходимость в
проверке статистического качества его выходных последовательностей, точнее,
в проверке гипотезы H0 о независимости и равновероятности битов выходных
последовательностей. Проверку H0 рекомендуется выполнять в соответствии с 
методикой [МИ.10127.12.03](https://apmi.bsu.by/resources/met) "Методика
статистического тестирования выходных последовательностей генераторов случайных
чисел" (лексема `12` в названии методики указывает на версию 1.2).

Пример реализации статистических тестов методики МИ.10127.12.03 представлен в
модуле [`h0test.py`](h0test.py).
